# מערכת צ'אט TCP

**גיתם ולהב מציגים:** פרויקט בקורס רשתות תקשורת - אפליקציית צ'אט בזמן אמת עם Backend ב-TCP ו-Frontend ב-React.

## איך מפעילים?

### 1. מתקינים ספריות

```bash
cd backend
pip install -r requirements.txt

```

### 2. מפעילים את השרת

```bash
python server.py

```

### 3. מפעילים את צד הלקוח (Client)

קיימות שתי אפשרויות לבדיקת הצ'אט:

#### אפשרות א': לקוח טרמינל (המקור)

```bash
python client.py

```

אפשר לפתוח כמה מופעים של הטרמינל שרק תרצו כדי לבדוק את כל מה שעשינו !

#### אפשרות ב': ממשק ווב (פיצ'ר בונוס! 🎨)

בנינו ממשק GUI מעוצב ב-React!

**הערה:** דרישות הפרויקט היו לבנות את המערכת **ללא** websockets. **אבל**, כדי לממש ממשק משתמש (GUI) מודרני, היינו חייבים להשתמש ב-websocket.
בשל כך, הוספנו בונוס (בנוסף ל-server.py המקורי): "גשר" WebSocket פשוט שמעביר הודעות בזמן אמת - חשבו על זה כפיצ'ר בונוס שמאפשר לכם לבדוק את ה-Frontend המושקע שלנו!

**שלב 1:** הפעלת השרת עם גשר ה-WebSocket:

```bash
python start_for_frontend.py

```

זה יפעיל גם את שרת ה-TCP וגם את גשר ה-WebSocket.

**שלב 2:** הפעלת ה-Frontend:

```bash
cd frontend-chat
npm install
npm run dev

```

לאחר מכן פתחו את האפליקציה בדפדפן. ניתן לפתוח מספר טאבים כדי לסמלץ מספר משתמשים!

### 4. בונוס: תסריט דמו (Demo)

רוצים לראות את המערכת בפעולה ללא בדיקה ידנית? הריצו את הדמו שלנו:

```bash
cd backend
python demo.py

```

הסקריפט מפעיל אוטומטית את השרת ומחבר 4 לקוחות (אליס, בוב, צ'ארלי ודיאנה) שמנהלים שיחה ביניהם. חשבנו שזו תהיה אחלה דרך להראות לכם איך הכל עובד!

## הוראות שימוש

### לקוח טרמינל

1. הזינו שם משתמש כאשר תתבקשו.
2. שלחו הודעות בפורמט: `username:your message`
3. הקלידו `list` כדי לראות משתמשים מחוברים.
4. הקלידו `everyone:message` כדי לשלוח הודעה לכולם (Broadcast).
5. הקלידו `exit` כדי להתנתק.

### ממשק ווב (Web Frontend)

1. פתחו את האפליקציה בדפדפן.
2. הזינו שם משתמש כדי להתחבר.
3. בחרו משתמש ספציפי או "Everyone" מהתפריט הנגלל.
4. הקלידו את ההודעה ושלחו.

## מבנה הפרויקט

* `backend/` - שרת ה-TCP בפייתון וגשר ה-WebSocket.
* `frontend-chat/` - אפליקציית ה-React (צד לקוח).
* `client.py` - לקוח מבוסס טרמינל.

## דרישות מערכת

* Python 3.6+
* Node.js ו-npm (עבור ה-Frontend)
* חבילת `websockets` (מותקנת דרך requirements.txt)
